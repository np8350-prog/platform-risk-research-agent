Anthropic’s data handling policies vary based on whether you are using Commercial Services (Anthropic API, Claude Console, Claude for Work / Team / Enterprise) or Consumer Services (Claude Free, Pro, Max at claude.ai).

1. What Data They Collect & Store
	•	Prompts & Outputs: User prompts, attachments, system instructions, and generated completions. 
	•	Account & Billing Data: Account email, workspace details, user profile info, and payment records (processed via Stripe). 
	•	Telemetry & Technical Logs: IP addresses, browser/device metadata, usage metrics, error logs, and session interactions. 
	•	Identity Verification Data: For consumer accounts undergoing anti-abuse checks, identity/age verification data via third-party partners. 
2. Where Data is Hosted (Region & Cloud Providers)
	•	Cloud Infrastructure Providers: Anthropic relies on Amazon Web Services (AWS), Google Cloud Platform (GCP), and Microsoft Azure as primary infrastructure subprocessors.  
	•	Data Location at Rest: Data stored directly through claude.ai or the first-party Anthropic API is stored at rest in United States data centers by default.  
	•	Inference Geo Controls: For first-party API users, Anthropic supports an inference_geo parameter (e.g., locking execution to US regions).  
	•	EU Data Residency: Direct Anthropic API or Enterprise plans do not offer native EU data residency at rest. Organizations requiring strict EU data isolation must deploy Claude models through AWS Bedrock (EU profiles in Frankfurt, Ireland, Paris) or Google Cloud Vertex AI (EU regions).  
3. Data Retention Policy
	•	Commercial Services (API & Claude for Work): 
	◦	Default Retention: Prompts and responses are retained for 30 days for safety monitoring and abuse detection before deletion.  
	◦	Zero Data Retention (ZDR): Available for eligible enterprise API customers, where prompt and output data are processed strictly in-memory and not stored on disk (except where flagged for safety review). 
	•	Consumer Services (claude.ai Free, Pro, Max): 
	◦	Standard (Opt-Out): Conversations are retained for 30 days.  
	◦	Training Opt-In: If a consumer user opts in to the "Improve Claude for everyone" setting, retention extends up to 5 years in de-identified form.  
	•	Policy Violations & Feedback Exceptions: 
	◦	Sessions flagged for Acceptable Use Policy violations are retained for up to 2 years, with safety classification metadata stored for up to 7 years.  
	◦	User feedback (e.g., thumbs up/down, bug reports) is kept for up to 5 years.  
4. Use of Customer Data for Model Training
	•	Commercial / API Users: No. Anthropic explicitly commits not to train its foundation models on customer prompts, completions, or workspace data submitted via the API, Claude Console, or Enterprise plans. 
	•	Consumer Web Users: Opt-In Only. Consumer chats (Free, Pro, Max) and Claude Code sessions are not used for training by default. Training occurs only if a user explicitly opts in via settings or manually submits feedback/ratings.
