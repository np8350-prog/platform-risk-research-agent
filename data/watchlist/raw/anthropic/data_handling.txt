•	Data Collected & Stored: System prompts, completion outputs, user account metadata, operational logs, payment history, and usage analytics (https://trust.anthropic.com/subprocessors) (https://anarlog.so/blog/anthropic-data-retention-policy/). 
	•	Hosting Locations: Infrastructure hosted across Google Cloud Platform (GCP), Amazon Web Services (AWS), and Microsoft Azure data center regions worldwide (https://trust.anthropic.com/subprocessors). 
	•	Retention Policy: 
	◦	Commercial API & Enterprise Users: Default log retention is 7 days (reduced from 30 days in late 2025), expandable up to 30 days upon request via DPA (https://anarlog.so/blog/anthropic-data-retention-policy/). 
	◦	Zero Data Retention (ZDR): Available for qualifying Enterprise API accounts, where inputs and outputs are retained in volatile memory only long enough to execute real-time automated trust and safety screening (https://anarlog.so/blog/anthropic-data-retention-policy/). 
	◦	Consumer Accounts (Free, Pro, Max): Account data and chat history may be retained up to 5 years for model training unless the user manually toggles off data usage in privacy settings (https://rits.shanghai.nyu.edu/ai/understanding-anthropics-data-usage-policy-what-users-need-to-know/). 
	•	Training on Customer Data: Customer inputs and outputs submitted through the commercial API or Claude Enterprise plans are never used to train Anthropic's foundation models (https://rits.shanghai.nyu.edu/ai/understanding-anthropics-data-usage-policy-what-users-need-to-know/) (https://anarlog.so/blog/anthropic-data-retention-policy/). 
	•	Subprocessors & Third Parties: Key subprocessors include Amazon Web Services, Google Cloud Platform, Microsoft Azure, Cloudflare (CDN/routing), Stripe (billing), WorkOS (SSO/identity), Intercom, Twilio, Sentry, Sift, Arkose Labs, Brave Search (web search capabilities), ElevenLabs (voice synthesis), and Palantir (government cloud hosting) (https://trust.anthropic.com/subprocessors).
