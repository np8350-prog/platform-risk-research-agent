A vulnerability was identified on GitHub (Issue #4556) concerning unauthorized use of external image hosting, where an attacker could intercept assistant creation requests and modify the "pictureUrl" field to include an image hosted on a different server or a link to a large file, potentially leading to denial-of-service (DoS) attacks (https://github.com/dust-tt/dust/issues/4556). No data breaches, major outages, or lawsuits related to data handling or security beyond this single vulnerability were found in the search results.
