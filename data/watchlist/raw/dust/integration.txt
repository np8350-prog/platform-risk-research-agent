Dust offers a RESTful API for custom integrations, Webhook support for event-driven workflows, MCP (Model Context Protocol) for proprietary systems, OAuth2 for third-party app permissions, bi-directional sync (read + write actions), and incremental data refresh (https://www.dust.tt/developers/docs). The platform provides over 100 connectors to data sources and business software (https://www.dust.tt/connectors). Dust positions itself as having no vendor lock-in, allowing users to switch between best-in-class models (OpenAI, Anthropic, Google, Mistral) without rewriting logic and to redeploy agents to different models (https://www.dust.tt/developers/docs). A technical user can export data using the Open API (https://www.dust.tt/developers/docs). However, some comparison sites note "no public API available" (https://volvenix.com/en/tools/compare/dust-tt-vs-ainize-ai-3/), and advanced governance controls may be enterprise-only. Overall lock-in risk appears low due to model flexibility and Open API access, though complex workflows may create operational dependency.
