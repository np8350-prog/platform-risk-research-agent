**Integration Methods:**- **Public API** (GraphQL) providing programmatic access to vendor data, document uploads, report generation, and automation- **Reporting API** available at `https://graphql.whistic.com` requiring an API key- **Webhook** integrations- **BETA MCP (Model Context Protocol)** server for AI assistant integration- **No-code** built-in reporting features for simple exports**Data Export & Switching:** - Data can be pulled via API (contact CSM)- Reports can be exported as Excel files- **Critical limitation:** The API is "designed for dynamic scripts and automation rather than simple data exports" and "responses require programming knowledge to aggregate and process effectively"- Users have reported **difficulty with mass data export** for external reporting tools- No documented data portability or bulk export feature was found**Dependencies:**- Built on **AWS Bedrock** for AI capabilities- Relies on AWS infrastructure for hosting and security**Breaking Changes:** No known integration failures or breaking changes reported by users were found.**Lock-in Risk:** Medium.
