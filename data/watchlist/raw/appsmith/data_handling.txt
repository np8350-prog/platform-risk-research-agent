**What data is collected and stored:** Appsmith collects:- **Personal Data:** Trackers, Usage Data, and credentials for third-party integrations- **User data processed through apps:** Appsmith's backend **does not store** any data returned from user API/database queries or user inputs. It acts as a **proxy layer** only- **Appsmith AI data:** Chat completion data is processed via OpenAI's APIs and is **transient—not stored, logged, or retained**. File uploads generate embeddings stored in PostgreSQL, but original files are not stored**Where data is hosted:** Appsmith Cloud is hosted on **AWS data centers**. Specific regions are not published.**Data retention policy:** By default, Appsmith does not store user data processed through its services; it is "transient in nature". User Personal Data retention is outlined in the privacy policy.**Model training:** Appsmith does **not** use customer data to train models. Appsmith AI uses OpenAI's APIs but does not store or retain response data.**Subprocessors/third parties:** Appsmith shares data with:- **OpenAI** (for Appsmith AI features—chat completions and embeddings)- Third-party technical service providers, hosting providers, IT companies, and communications agencies- Appsmith does **not sell personal data** or exchange it for monetary value**Policy clarity:** The data handling policy is clearly documented in the security documentation and privacy policy. The key differentiator—that Appsmith does not store query response data—is prominently stated.
