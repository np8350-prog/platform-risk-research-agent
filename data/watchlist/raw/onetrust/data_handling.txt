OneTrust collects customer administrative metadata, user access details, risk evaluation records, Data Subject Access Requests (DSARs), consent records, and third-party vendor assessment documentation (https://www.enzuzo.com/blog/onetrust-review) (https://my.onetrust.com/s/article/UUID-9743079f-da29-65f6-17ee-ff518e05c4b7). Primary SaaS tenant data is hosted on Microsoft Azure with regional choices across the United States, Canada, Brazil, United Kingdom, Europe, Australia, and Asia (https://my.onetrust.com/s/article/UUID-21f6bff2-1b12-8c67-e8b0-d852e36f37af). Select acquired components (such as Tugboat Logic or Planetly) are hosted on Amazon Web Services (AWS) in the US, Canada, Europe, and Germany (https://my.onetrust.com/s/article/UUID-21f6bff2-1b12-8c67-e8b0-d852e36f37af).

System backups on Microsoft Azure are maintained continuously (full backups weekly, differential every 12–24 hours, and transactional logs every 5–10 minutes) with a 14-day retention window, and stored encrypted with AES-256 (https://my.onetrust.com/s/article/UUID-21f6bff2-1b12-8c67-e8b0-d852e36f37af) (https://my.onetrust.com/articles/es/Knowledge/UUID-21f6bff2-1b12-8c67-e8b0-d852e36f37af). OneTrust does not use customer tenant data to train public or foundational artificial intelligence models without explicit user consent (https://privacyportal.onetrust.com/webform/ee5f2be9-45a3-41f1-bea3-082ff8a4f1a3/97c14c4f-b3f8-4e89-9b64-6bf4208e39b2). Approved subprocessors include Microsoft Azure, regional corporate affiliates (e.g., OneTrust LLC, OneTrust Technology Limited, OT Privacy Software Pvt Ltd), and operational tool providers (https://my.onetrust.com/s/article/List-of-Subprocessors?language=en_US).
