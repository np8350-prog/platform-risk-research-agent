•	SOC 2: Amazon Bedrock is currently listed as in scope for AWS SOC 1, SOC 2 and SOC 3 reporting, excluding Amazon Bedrock Marketplace. (https://aws.amazon.com/compliance/services-in-scope/SOC/)
	•	SOC 2 type: AWS states that its SOC 2 reports are independent third-party examination reports. AWS specifically identifies its SOC 2 reports as covering Security, Availability, Confidentiality and Privacy. (https://aws.amazon.com/compliance/soc-faqs/)
	•	SOC 2 auditor: The independent auditor is Ernst & Young LLP (EY), which performs AWS SOC 1, SOC 2 and SOC 3 audits. This is independently confirmed by AWS's compliance documentation, although the actual SOC 2 report is distributed through AWS Artifact. (https://aws.amazon.com/compliance/soc-faqs/)
	•	Type I vs Type II: AWS documentation confirms the availability of SOC reporting and historical AWS SOC 2 Type II reporting; AWS's 2023 announcement explicitly describes the SOC 2 report as covering operating effectiveness over a period of time. Bedrock was added to the SOC scope in 2023. (https://aws.amazon.com/blogs/security/fall-2023-soc-reports-now-available-with-171-services-in-scope/) For current procurement, the exact latest Bedrock-specific SOC 2 report and coverage period should be retrieved from AWS Artifact. (https://aws.amazon.com/compliance/soc-faqs/)
	•	ISO 27001: Amazon Bedrock is currently listed within AWS's ISO-certified services. AWS states that AWS is certified against ISO/IEC 27001:2022, among other ISO standards. (https://aws.amazon.com/de/compliance/iso-certified/)
	•	ISO auditor/registrar: AWS states that its ISO/IEC 27001:2022 certification is verified by EY CertifyPoint, an ISO certification body accredited by the Dutch Accreditation Council. This is an independent certification rather than merely an AWS self-attestation. (https://aws.amazon.com/de/compliance/iso-27001-faqs/)
	•	GDPR: AWS states that customers can use Amazon Bedrock in compliance with GDPR, and AWS provides a GDPR-compliant Data Processing Addendum. GDPR compliance is therefore partly dependent on the customer's architecture, configuration and processing activities rather than being a blanket certification of every workload. (https://aws.amazon.com/bedrock/security-compliance/) (https://aws.amazon.com/blogs/machine-learning/implementing-knowledge-bases-for-amazon-bedrock-in-support-of-gdpr-right-to-be-forgotten-requests/)
	•	HIPAA: Amazon Bedrock is listed by AWS as HIPAA eligible. HIPAA eligibility is not equivalent to an independent "HIPAA certification"; the customer remains responsible for configuring and operating its workload appropriately. (https://aws.amazon.com/about-aws/whats-new/2023/09/amazon-bedrock-generally-available/) (https://aws.amazon.com/bedrock/security-compliance/)
	•	PCI DSS: Amazon Bedrock is currently in scope for PCI DSS, excluding Amazon Bedrock Marketplace. (https://aws.amazon.com/compliance/services-in-scope/PCI/) AWS states that Coalfire, a third-party Qualified Security Assessor, evaluated AWS for the PCI DSS certification. (https://aws.amazon.com/blogs/security/latest-pci-dss-v4-0-compliance-package-available-in-aws-artifact/)
	•	FedRAMP: Amazon Bedrock is currently listed as FedRAMP certified in both the FedRAMP Moderate/Class C commercial boundary and FedRAMP High/Class D GovCloud boundary. AWS's current scope page explicitly lists Bedrock in both. (https://aws.amazon.com/compliance/services-in-scope/FedRAMP/)
	•	Important compliance caveat: Compliance scope applies to specified AWS services, regions and features; it does not automatically make the customer's application compliant. AWS explicitly describes compliance as a shared responsibility. (https://docs.aws.amazon.com/bedrock/latest/userguide/compliance-validation.html)
	•	Overall compliance assessment: Strong. Bedrock is considerably more mature from a compliance perspective than a typical standalone AI startup, but procurement should obtain the current SOC 2 report through AWS Artifact and verify the exact region/model/feature being used.
