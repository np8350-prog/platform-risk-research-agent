•	Major AWS outage: AWS experienced a major US-EAST-1 disruption on October 20, 2025. AWS reported increased error rates across services caused by DNS-resolution problems involving regional DynamoDB endpoints; recovery was completed later that day. This was an AWS infrastructure incident rather than a demonstrated Bedrock data breach. (https://www.aboutamazon.com/news/aws/aws-service-disruptions-outage-update)
	•	Bedrock-specific impact: Public user reports indicate that some Bedrock invocations experienced errors around the October 2025 AWS outage, although I found no AWS statement establishing a Bedrock-specific data-loss incident. (https://www.reddit.com/r/aws/comments/1qt3gne/aws_bedrock_in_production_anyone_else_finding_it/)
	•	AgentCore sandbox security issue: BeyondTrust disclosed in March 2026 that Amazon Bedrock AgentCore Code Interpreter's Sandbox mode allowed DNS queries that could be used for command-and-control and DNS-based data exfiltration in certain configurations. AWS subsequently remediated the DNS tunneling vector in April 2026. The issue was reported to AWS through HackerOne. (https://www.beyondtrust.com/blog/entry/aws-bedrock-agentcore-sandbox-breakout)
	•	CVE-2026-11393: AWS disclosed a code-injection vulnerability in the Bedrock AgentCore CLI. An authenticated user in the same AWS account could inject Python code through improperly escaped collaborationInstruction data. AWS fixed it in version 0.14.2 and later versions. (https://aws.amazon.com/security/security-bulletins/2026-040-aws/)
	•	CVE-2026-15737: AWS disclosed a sensitive-content disclosure issue in the Bedrock AgentCore Python SDK. Affected versions could write raw user prompts and complete agent responses into OpenTelemetry spans in CloudWatch Logs, where users with appropriate CloudWatch access could potentially read them. AWS fixed this in version 1.5.1. (https://aws.amazon.com/security/security-bulletins/2026-058-aws/)
	•	Credential/account compromise involving Bedrock: In July 2026, Darktrace reported an incident in which an EC2-hosted AI gateway connected to Bedrock was compromised and subsequently used for cryptomining. The evidence did not establish that Bedrock itself was breached; the initial compromise was apparently through an externally exposed SSH service on the customer's EC2 instance. (https://www.techradar.com/pro/security/cryptomining-can-be-a-lucrative-post-compromise-activity-in-cloud-environments-experts-warn-ai-gateways-connected-to-amazon-bedrock-are-being-hijacked-to-steal-crypto)
	•	Data-handling lawsuits: I found no credible lawsuit specifically establishing that Amazon Bedrock itself suffered a customer-data breach or security/privacy violation. No URL available for this negative finding.
	•	Risk conclusion: There is no evidence from the sources reviewed of a confirmed Bedrock-wide customer-data breach. However, Bedrock/AgentCore has had several security vulnerabilities and operational incidents, so it should not be treated as incident-free.
