Several security and reliability incidents have been reported:- **May 2024 – "LLMjacking" attack**: Attackers exploited stolen cloud credentials obtained through a vulnerable Laravel system (CVE-2021-3129) to abuse AI cloud services, including AWS Bedrock. *Source: Incident Database (incidentdatabase.ai)*.- **Late 2025 – Regional outages**: Developer sentiment references "recent regional outages in late 2025" affecting Bedrock. Specific details are limited, but the outages are mentioned in multiple community discussions.- **May 2026 – 15+ hour outage**: A reported outage of 15 hours and 54 minutes. *Source: Community discussion (Substack/Reddit)*.- **September 2025–March 2026 – AgentCore sandbox escape vulnerability (CVE-2026-15737)**: BeyondTrust discovered a vulnerability allowing DNS exfiltration from Bedrock AgentCore's "isolated" sandbox. Reported via HackerOne on September 1, 2025; AWS deployed an initial fix in November 2025. A separate vulnerability (CVE-2026-15737) involved sensitive content disclosure via OpenTelemetry spans in the AgentCore Python SDK. *Source: BeyondTrust disclosure, AWS CVE listing*.- **April 2026 – AgentCore sandbox escape (Unit 42)**: Palo Alto Networks' Unit 42 published research on escaping the AWS AgentCore sandbox, with responsible disclosure to AWS.- **June–July 2026 – Cryptomining on exposed Bedrock AI gateway**: Darktrace reported that attackers compromised a publicly exposed AWS EC2 instance running LiteLLM as an AI gateway to Bedrock and deployed the XMRig cryptominer. The instance was shut down after detection. *Source: Darktrace, SiliconANGLE, Expert Insights*.- **August 2026 – AgentCore InvokeHarness API flaw (CoreBreak)**: Security researchers disclosed "CoreBreak" at Black Hat USA 2026—structural flaws in the tool-dispatch layers of AWS Bedrock AgentCore. AWS stated the issue affected the managed InvokeHarness API before July 31, 2026. *Source: The Hacker News, Cloud Security Alliance*.- **No known data breaches** of Bedrock itself have been publicly reported; all incidents involve misconfigured customer infrastructure or vulnerabilities in the AgentCore feature, not a breach of the Bedrock service's core data plane.
