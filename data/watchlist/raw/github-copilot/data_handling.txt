- **What Data is Collected**: GitHub Copilot collects **interaction data** from Free, Pro, and Pro+ users, including inputs, outputs, code snippets, and associated context. It also collects file names, repository structure, navigation patterns, and user feedback. Private repository content "at rest" is not used for training, but Copilot processes code from private repositories when actively used.- **Data Retention Policy**: Specific retention periods are not explicitly published in the search results.- **Model Training**: **Yes**, GitHub uses interaction data from Copilot Free, Pro, and Pro+ users to train and improve its AI models **by default** as of **April 24, 2026**. Users can **opt out** in their Copilot settings under "Privacy". **Copilot Business and Enterprise users are not affected**.- **Data Hosting & Residency**: GitHub supports **data residency for US and EU regions** with FedRAMP-authorized models. Administrators can restrict their organization to data-resident or FedRAMP-compliant models.- **Subprocessors & Third Parties**: Interaction data may be shared with **GitHub affiliates, including Microsoft**. Data is **not** shared with third-party AI model providers or other independent service providers.
