•	SOC 2: GitHub Enterprise Cloud provides a SOC 2 Type II report. GitHub's documentation identifies SOC 2 Type 2 as one of the compliance reports available to enterprise customers. (https://docs.github.com/en/enterprise-cloud@latest/admin/overview/accessing-compliance-reports-for-your-enterprise) This is an independently audited report rather than merely a GitHub self-attestation; however, the public page does not name the auditor. Named auditor: no URL available for this.
	•	ISO 27001: GitHub Enterprise Cloud has an ISO/IEC 27001:2022 certification. GitHub's compliance documentation identifies the certification as available to enterprise customers. (https://docs.github.com/en/enterprise-cloud@latest/admin/overview/accessing-compliance-reports-for-your-enterprise) This is an external certification rather than merely a self-claim. Named registrar: no URL available for this.
	•	FedRAMP: GitHub Enterprise Cloud is FedRAMP authorized, and GitHub's October 2024 announcement specifically stated that GitHub Enterprise Cloud was already FedRAMP authorized while GitHub pursued expanded FedRAMP Moderate authorization. (https://github.com/newsroom/press-releases/github-to-pursue-fedramp-moderate)
	•	Copilot FedRAMP: GitHub now provides a policy that allows eligible GitHub Enterprise Cloud customers with US data residency to restrict Copilot to models with FedRAMP Moderate certification. (https://docs.github.com/en/copilot/concepts/models/fedramp-models) This does not mean every Copilot model or every Copilot deployment is automatically FedRAMP compliant; the organization must use the eligible configuration and permitted models.
	•	GDPR: GitHub states that it and customers can enter into a Data Protection Agreement supporting GDPR and similar data-protection laws. (https://github.com/features/copilot/copilot-business) This is a contractual compliance mechanism, not a claim that Copilot is independently "GDPR certified."
	•	HIPAA / BAA: GitHub's enterprise compliance documentation discusses HIPAA-related deployment patterns, but I did not find sufficiently explicit current documentation establishing that GitHub Copilot itself universally offers a standalone HIPAA BAA covering every Copilot feature/model. No URL available for a blanket Copilot HIPAA/BAA claim.
	•	PCI DSS: GitHub makes a PCI DSS Attestation of Compliance available to enterprise customers. (https://docs.github.com/en/enterprise-cloud@latest/admin/overview/accessing-compliance-reports-for-your-enterprise) This is an enterprise GitHub compliance artifact; it should not automatically be interpreted as a blanket certification of every Copilot feature.
	•	Independent verification: GitHub's compliance documentation explicitly distinguishes formal reports/certifications such as SOC 2 Type 2 and ISO/IEC 27001:2022 from its CSA CAIQ self-assessment. (https://docs.github.com/en/enterprise-cloud@latest/admin/overview/accessing-compliance-reports-for-your-enterprise)
	•	Compliance conclusion: Strong, but feature/model/region dependent. Enterprise customers should verify the precise Copilot plan, data-residency configuration and models covered by the relevant compliance report before treating the entire Copilot deployment as compliant.
