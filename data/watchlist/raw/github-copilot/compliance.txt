GitHub Copilot holds multiple industry-standard certifications. The information below is primarily based on **GitHub's own claims** on their trust center and website, though SOC reports are available upon request.- **SOC 1, SOC 2, SOC 3**: GitHub Copilot holds **SOC 1, SOC 2, and SOC 3** certifications. Full audit reports, including **SOC 1 Type 2 and SOC 2 Type 2**, are available via a gated access request.- **ISO 27001:2013**: GitHub Copilot holds **ISO 27001:2013** certification.- **ISO/IEC 42001:2023**: GitHub Copilot holds the international standard for **AI management systems**.- **CSA STAR Level 2**: GitHub Copilot holds this certification.- **TISAX**: GitHub Copilot holds TISAX certification.- **GDPR**: GitHub Copilot is designed to support GDPR compliance.- **FedRAMP**: GitHub has shipped FedRAMP-authorized models.
