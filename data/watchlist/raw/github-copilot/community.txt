Developer sentiment on Reddit, Hacker News, and G2 is mixed, with significant frustration around recent pricing changes and concerns about model quality.**Common Praise / Strengths:**- **Market Leader**: GitHub Copilot is widely regarded as one of the strongest and most adopted AI coding assistants, with a **4.5/5 rating on G2**.- **Real-time Code Suggestions**: Users praise its real-time code completions and autocompletion directly inside the IDE.- **Beginner-Friendly**: Junior developers benefit from seeing idiomatic patterns and learning proper syntax.- **Team Utility**: Teams appreciate on-demand code completions, error explanations, and test case generation within VS Code or JetBrains.**Common Complaints / Frustrations:**- **Pricing Backlash (2026)**: A major source of frustration is the switch to a token/credit-based billing model. Users report massive cost increases—some claim their monthly bill would jump from ~$29 to nearly **$750**. One user reported using 4,000 out of 20,000 credits in a single day.- **Model Quality Degradation**: Multiple users in GitHub discussions and Reddit have reported that Copilot's models are "getting progressively worse" and that the difference from older versions is "noticeable," with some canceling subscriptions.- **Agent Mode Issues**: Users report that Copilot Agent Mode doesn't work as advertised, with issues like hallucinated APIs and cost surprises from agents stuck in loops.- **Developer Trust**: Senior developers express frustration with teammates blaming Copilot for code errors, using "Copilot suggested that" as an excuse.- **"Marketing Scam" Sentiment**: Some users feel Copilot is overhyped, describing it as more useful for beginners than experienced developers.**Signs of Users Leaving**: There are signs of user churn due to the new pricing model and perceived model degradation. Competitors like **Cursor** (valued at $2.5B) and **Claude Code** are gaining traction. However, Copilot, Claude Code, and Cursor together control over 70% of the $4 billion market.
