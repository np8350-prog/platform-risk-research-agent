•	June 17, 2026 Copilot outage: GitHub reported that between approximately 03:35 and 04:44 UTC, Copilot was degraded and most frontier chat models were temporarily unavailable across all regions. A configuration change was identified as the cause and reverted. (https://eu.githubstatus.com/posts/details/PGKR188)
	•	June 26–28, 2026 Cloud Agent incident: Copilot Cloud Agent was degraded from June 26 through June 28. Built-in agent tool calls had an average error rate of approximately 8%, peaking at approximately 26% hourly. GitHub attributed the problem to a regression in a Copilot Cloud Agent runtime deployment. (https://www.githubstatus.com/history)
	•	July 9, 2026: GitHub Actions experienced a severe incident in which approximately 96% of GitHub-hosted Actions runs temporarily failed to start; Copilot Cloud Agent and Copilot Code Review also failed to start for approximately 30 minutes because they depended on Actions infrastructure. (https://www.githubstatus.com/index.html)
	•	July 20, 2026 model-provider outage: GitHub reported degraded Copilot performance for GPT-5.3 Codex because an upstream provider was returning errors. GitHub automatically rerouted traffic and recommended selecting another model. (https://www.githubstatus.com/)
	•	May 28, 2026 upstream-model incident: Copilot experienced elevated errors for GPT-5.2, GPT-5.3-Codex, GPT-5.4 and GPT-5.5 because of an issue with an upstream provider's Responses API. Copilot coding agent and code review were also affected. (https://www.githubstatus.com/history)
	•	Security/data-leak concerns: A 2026 academic study analyzing Stack Overflow, Reddit and Hacker News discussions about GitHub Copilot identified four major security concern categories: potential data leakage, code licensing, adversarial attacks/prompt injection, and insecure code suggestions. (https://arxiv.org/abs/2604.08352)
	•	Generated-code vulnerabilities: An academic study testing Copilot-generated C/C++ code found that Copilot reproduced vulnerable code in approximately 33% of the tested vulnerability scenarios, although it also reproduced fixed code in approximately 25% and was not consistently vulnerable across vulnerability classes. (https://arxiv.org/abs/2204.04741)
	•	Copyright lawsuit: In November 2022, plaintiffs filed a class-action lawsuit against GitHub, Microsoft and OpenAI alleging that Copilot's training and generated output violated copyright and open-source licensing rights. (https://githubcopilotlitigation.com/) Reddit discussion of the litigation is also available here. (https://www.reddit.com/r/programming/comments/13fbnte/github_and_openai_fail_to_wriggle_out_of_copilot/)
	•	Data-handling/security lawsuit: I found no credible evidence of a court finding that GitHub Copilot itself suffered a customer-data breach. No URL available for this negative finding.
	•	Operational risk: The incident history demonstrates a meaningful dependency on upstream AI model providers and GitHub Actions infrastructure. This is an important vendor-risk consideration even though the underlying vendor is highly stable.
