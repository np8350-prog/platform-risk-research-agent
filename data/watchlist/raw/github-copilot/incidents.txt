GitHub Copilot has experienced several **service outages** and **security vulnerabilities** (CVEs), but **no major data breaches** of the Copilot service itself have been publicly reported.**Service Outages:**- **January 13, 2026**: A service outage lasting from 09:25 to 10:11 UTC, with error rates averaging 18% and peaking at 100%.- **January 29, 2025**: Copilot Chat on github.com was degraded for over two hours (14:00–16:28 UTC) due to a change in client-side identifiers.- **March 19–20, 2026**: The Copilot Coding Agent service was degraded, preventing users from starting new sessions.- **April 24, 2025**: A service outage in the European and Australian regions due to a misconfigured background job.- **May 20, 2025**: A misconfiguration in load distribution caused a 50% error rate for Copilot Code Completions in the Americas.- **May 28, 2026**: Service degradation due to an issue with an upstream model provider's Responses API.- **June 16, 2026**: Degraded availability for the Opus 4.8 model due to an upstream provider issue.**Security Vulnerabilities (CVEs & Research):**- **CVE-2025-53773 (2025)**: A command injection vulnerability in GitHub Copilot and Visual Studio, triggerable via prompt injection, potentially leading to remote code execution (RCE).- **CVE-2025-62453 (November 2025)**: A security feature bypass vulnerability due to improper validation of generative AI output.- **CVE-2025-64660 (November 2025)**: Improper access control allowing an authorized attacker to execute code over a network.- **CVE-2025-66389 (November 2025)**: A critical vulnerability in GitHub Copilot 1.372.0 allowing filesystem access outside a workspace folder and potential exfiltration via prompt injection.- **CVE-2026-47282 (July 2026)**: An information disclosure vulnerability due to insufficiently protected credentials.- **CVE-2026-50519 (June 2026)**: An information disclosure vulnerability due to insecure default initialization of network resources.- **"CamoLeak" (June 2025, CVSS 9.6)**: A critical vulnerability in GitHub Copilot Chat discovered by Legit Security that allowed silent exfiltration of secrets and source code from private repositories. It combined a CSP bypass with remote prompt injection. GitHub fixed it by disabling image rendering in Copilot Chat.- **Incident 1174 (February 2025)**: Lasso Security reported that Microsoft Copilot could return content from GitHub repositories that had been public briefly but later set to private or deleted, due to Bing's caching system.- **Agentic Workflows Leak (July 2026)**: The Register reported that GitHub's AI agents could be tricked into pulling data from private repositories and leaking it.**Lawsuits:**- ***Doe v. GitHub, Microsoft, and OpenAI* (Filed November 2022)**: A class-action lawsuit alleging that GitHub Copilot was trained on publicly available source code without complying with open-source licenses and removed copyright management information, violating the DMCA, CCPA, and other laws. The case was still being argued as of 2026.
