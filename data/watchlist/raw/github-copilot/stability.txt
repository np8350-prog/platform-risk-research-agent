GitHub Copilot is not an independent startup/vendor; it is a product of GitHub, which is owned by Microsoft. GitHub was founded in 2008 and Microsoft announced its acquisition of GitHub for $7.5 billion in Microsoft stock on June 4, 2018. (https://news.microsoft.com/2018/06/04/microsoft-to-acquire-github-for-7-5-billion/) GitHub Copilot was launched as a technical preview in 2021. (https://github.blog/news-insights/product-news/introducing-github-copilot-ai-pair-programmer/)
	•	Founding / operating history: GitHub was founded in 2008; Copilot has operated since its 2021 launch. (https://github.blog/news-insights/product-news/introducing-github-copilot-ai-pair-programmer/)
	•	Funding rounds: GitHub raised venture funding before its Microsoft acquisition, including a $100 million Series B in July 2012 led by Sequoia Capital and a $250 million Series C in July 2015 led by Sequoia Capital. (https://github.com/about/press) However, Copilot itself has no separate funding rounds because it is a GitHub/Microsoft product. No URL available for this specific negative finding.
	•	Acquisition: Microsoft acquired GitHub for $7.5 billion in 2018. (https://news.microsoft.com/2018/06/04/microsoft-to-acquire-github-for-7-5-billion/)
	•	Team size: GitHub does not publicly disclose a separate Copilot employee headcount. No URL available for this.
	•	Scale: GitHub said in October 2024 that more than 77,000 organizations had adopted GitHub Copilot. (https://github.com/newsroom/press-releases/github-to-pursue-fedramp-moderate) In July 2025, Microsoft reported that Copilot had passed 20 million all-time users; GitHub confirmed the figure represented all-time users rather than active monthly/daily users. (https://techcrunch.com/2025/07/30/github-copilot-crosses-20-million-all-time-users/)
	•	Layoffs: GitHub announced a reduction of approximately 10% of its workforce in 2022, followed by organizational changes under Microsoft. (https://www.theverge.com/2022/11/9/23449951/github-layoffs-10-percent-workforce-microsoft) This was a GitHub-wide workforce reduction, not a Copilot-specific shutdown signal.
	•	Leadership: GitHub CEO Thomas Dohmke announced in September 2024 that he would step down as CEO and transition to a strategic role within Microsoft. (https://github.blog/news-insights/company-news/github-ceo-thomas-dohmke-to-transition-to-new-role-at-microsoft/) GitHub subsequently appointed Mario Rodriguez as CEO. (https://github.blog/news-insights/company-news/mario-rodriguez-appointed-github-ceo/)
	•	Shutdown rumors: I found no credible evidence that Microsoft intends to shut down GitHub Copilot. GitHub continues to expand Copilot into agentic coding, cloud agents, SDKs, MCP integrations and multiple foundation models. (https://github.blog/ai-and-ml/github-copilot/copilot-faster-smarter-and-built-for-how-you-work-now/)
	•	Financial distress: There is no evidence of financial distress specific to GitHub Copilot. Microsoft owns the underlying business and continues investing in Copilot. No URL available for this negative finding.
	•	Overall stability: LOW vendor-failure risk. The principal vendor is Microsoft/GitHub rather than a venture-backed AI startup. The more relevant risk is product/model evolution, because Copilot increasingly depends on multiple external model providers and GitHub-controlled model routing.
