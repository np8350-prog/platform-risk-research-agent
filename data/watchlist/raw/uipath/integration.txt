•	Integration Methods: REST/OData APIs, native SDKs, Integration Service connectors (100+ pre-built API connectors for Salesforce, SAP, Workday), and desktop/web UI selectors/Computer Vision. 
	•	Vendor Lock-in & Exportability: High Lock-in Risk. Workflows are saved in proprietary XML-based XAML formats with custom C# or VB.NET code snippets. There is no automated exporter to transfer workflows to competing platforms (e.g., Power Automate or Automation Anywhere). Leaving UiPath requires completely re-architecting and rewriting automations from scratch. 
	•	Integration Breaking Changes: Changes in target application DOMs, browser updates, or third-party API deprecations can break automation selectors, requiring ongoing maintenance.  
	•	Underlying Dependencies: UiPath Automation Cloud relies heavily on Microsoft Azure for core infrastructure. GenAI features (Autopilot, AI Center) leverage integrations with Microsoft Azure OpenAI, Google Cloud, or AWS for OCR and model execution.
